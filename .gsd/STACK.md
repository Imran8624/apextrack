## Core Technologies

| Category | Technology | Version | Purpose |
|---|---|---|---|
| **Runtime** | Node.js | v20+ | Server-side JavaScript execution |

| **Language** | TypeScript | 5.x | Strict type safety and contracts |
| **UI Library** | React / React DOM | 19.2.8 | Concurrent rendering & component model |
| **Styling** | Tailwind CSS | 4.x | Utility-first CSS styling system |

## Development & Test Commands

- **Run Dev Server**: `npm run dev` (`node server.js`)
- **Type Checking**: `npx tsc --noEmit`
- **Linting**: `npm run lint`
- **Build**: `npm run build`
